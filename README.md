- 通过 ChatGPT 账号登录，在套餐包含的额度内使用 Codex；

## Codex 充值到底充的是什么？

先看你使用 Codex 的方式。

### 1. ChatGPT 套餐额度

如果你是在 Codex App、网页端、CLI 或 IDE 插件中使用 ChatGPT 账号登录，通常对应的是 ChatGPT 套餐权益。

官方 Codex 定价页面显示，Codex 已被纳入 ChatGPT 的 Free、Go、Plus、Pro、Business 和 Enterprise 等计划中。不同套餐的使用量、模型权限和任务限制不同，Codex 并不是一个完全独立于 ChatGPT 的普通会员产品。

简单理解：

- ChatGPT Plus：适合偶尔编程、代码审查、项目修改和日常开发；
- ChatGPT Pro：适合每天高频使用 Codex，通常拥有更高的任务量；
- Business / Enterprise：面向团队和企业工作区；
- Codex Credit：在账户已经达到套餐限额后，用额外额度继续使用部分 Codex 能力，具体是否可买取决于页面和账号状态。

所以，如果你只是想让 Codex 正常工作，第一步通常是确认当前账号是否有有效的 ChatGPT 套餐，而不是直接寻找 API 余额充值。

### 2. Codex Credit 或按量额度

Codex Credit 更接近“额外使用额度”，用于在套餐额度之外继续运行任务。

WildAI 的帮助中心明确提到，平台不提供 GPT 官方 API 额度充值，但支持 Codex 按用量的点数或额度充值。是否能购买，要打开订阅页面查看有没有 **Codex Credit** 入口；页面出现入口时才说明当前账号或当前阶段支持该服务。

这意味着，不能只凭搜索结果里的旧价格判断自己能不能充值。即使别人之前购买过 Codex Credit，你当前登录的账号、所在地区、产品状态或页面版本不同，也可能看不到相同选项。

### 3. OpenAI API 余额

OpenAI API 和 ChatGPT Plus 是两套独立的计费体系。

ChatGPT Plus 会员并不自动等于 API 账户有余额。反过来，API 账户里有余额，也不代表你可以用同一个 API Key 登录 Codex App 的官方 ChatGPT 模式。WildAI 的帮助中心也特别提醒，GPT Plus 与官方 API 分开计费，平台目前不提供 GPT 官方 API 额度充值。

如果你的报错包含以下内容，问题往往不是“没充值”：

- `401`
- `402`
- `Missing scopes`
- `token_revoked`
- `deactivated_workspace`
- `403 Forbidden`
- 无权访问 Codex 专用分组

其中，403 很可能是 Codex 被配置成了第三方 API 地址，而不是通过 ChatGPT 账号登录。此时继续充值 API 余额，通常解决不了问题。

## Codex 充值前，先判断你真正缺的是什么

可以按下面顺序排查。

### 情况一：Codex 完全打不开

先确认登录方式。

如果你使用的是 Codex App 或 CLI，应该使用 ChatGPT 账号登录。若配置了 API Key、第三方 Provider 或自定义 `BASE_URL`，可能会把 Codex 请求发送到不支持官方 Codex 权限的地址。

建议检查：

1. 是否选择了“使用 ChatGPT 登录”；
2. 是否登录了购买 Plus 或 Pro 的同一个账号；
3. 是否设置过第三方 API 地址；
4. 是否存在 `OPENAI_BASE_URL` 等环境变量；
5. 是否把 API Key 模式和 ChatGPT 账号模式混用了。

WildAI 的故障说明建议，遇到 403 时删除第三方 Provider 配置，重新选择官方 ChatGPT 登录，并使用已经开通套餐的账号。

### 情况二：Codex 可以使用，但额度很快用完

这种情况才更接近真正的“Codex 充值”。

你可以先查看 Codex 使用情况面板，确认是：

- 当前周期额度用完；
- 周额度触顶；
- 某个模型单独受限；
- 本地消息与云端任务共用额度；
- 账号套餐仍然有效，但额外 Credits 未启用。

官方页面说明，Codex 的使用限额会根据套餐、模型和任务类型变化，本地消息与云端聊天可能共用套餐额度。不同任务消耗也不一样，简单补全代码和长时间运行大型任务不能按同一个标准估算。

如果 WildAI 订阅页面有 Codex Credit 选项，可以按照页面购买。但如果没有入口，只能等待页面开放、升级支持的套餐，或通过官方账户页面查看是否存在额度购买选项。

### 情况三：你想给 API Key 充值

这就不是 ChatGPT Plus 或 Codex Credit 的问题了。

API Key 适合服务器、CI/CD、自动化脚本和团队共享环境。它按照模型调用的输入输出量计费，不等同于 ChatGPT 网页会员。

因此：

- 想在 Codex App 中用官方账号开发，优先看 ChatGPT Plus 或 Pro；
- 想让服务器自动调用模型，查看 API 平台的余额和计费设置；
- 想增加 Codex 套餐之外的使用量，查看 Codex Credit；
- 不要因为“API 余额不足”就购买 ChatGPT Plus；
- 不要因为“ChatGPT Plus 已开通”就认为 API Key 一定可用。

这几条看似基础，却是 Codex 充值搜索中最容易混淆的部分。

## 为什么付款后 Codex 还是不能用？

### 1. 购买了 Plus，但登录了另一个账号

Codex 的权益跟账号走，不跟浏览器、设备或付款邮箱自动绑定。

如果你有多个 ChatGPT 账号，最常见的问题就是：

- 付款时识别的是 A 账号；
- Codex App 登录的是 B 账号；
- 浏览器里缓存了另一个账号；
- 购买后退出登录又切换了账号。

解决方法是退出 Codex 和 ChatGPT，重新登录购买套餐的那个账号，再查看额度。

### 2. 购买的是会员，不是 API 余额

如果工具要求填写 API Key，ChatGPT Plus 通常不能直接替代 API Key。

这时应确认工具使用的是哪种登录方式：

- ChatGPT OAuth / 官方账号登录；
- OpenAI API Key；
- 第三方中转 API；
- 企业工作区账号。

四者的计费和权限并不一样。

### 3. 充值入口存在，但订单还没有完成

部分 Codex Credit 流程可能需要在交易记录中继续确认。付款成功后，进入订单页面查看是否还有“完成购买”“继续任务”或类似按钮。

不要看到“已付款”就立即关闭页面，也不要重复购买同一个档位。

### 4. 额度显示延迟

Codex 的额度页面有时不会立刻刷新。可以尝试：

- 退出后重新登录；
- 刷新使用情况页面；
- 重启 Codex App；
- 检查当前工作区；
- 确认使用的是正确模型；
- 等待几分钟后再查看。

如果 ChatGPT 套餐状态正常，但 Codex 额度异常或瞬间清零，WildAI 的帮助文档建议准备账单页、套餐状态、Codex 额度页面和异常时间，再联系客服核对。

## 退款和账号风险需要提前看清

购买第三方订阅服务时，不能只看“微信支付宝付款”或“失败退款”几个字。

WildAI 帮助中心说明，订单已经完成履约且权益生效后，因为选错产品、误操作或购买后不想使用，原则上不支持退款。尚未履约、订单仍在处理或服务未生效的情况，可以联系客服确认是否符合退款条件，但并不代表一定可以直接取消。

另外，平台教程中会涉及 Session、Cookie 或账号会话信息。它们不是普通的订单编号，而是可能影响账号登录状态的敏感凭证。操作时应遵守几个原则：

- 只在自己的设备和浏览器中登录；
- 不把密码、验证码、Cookie 或 Session Key 发给任何人；
- 不要把完整凭证截图发到群聊；
- 处理完成后检查账号安全设置；
- 不要在公共电脑上执行充值；
- 不要把平台客服发来的不明脚本直接复制运行。

如果你使用的是公司、学校或团队账号，还要确认组织管理员是否允许第三方代订阅或处理账号会话信息。
